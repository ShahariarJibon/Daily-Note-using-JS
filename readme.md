# 📝 Daily Note Take

A simple and interactive note-taking web application built with **HTML, CSS, and Vanilla JavaScript**.

This project was built as a practical JavaScript project to strengthen my understanding of DOM manipulation, event handling, state management, LocalStorage, and dynamic UI rendering.

## ✨ Features

- 📝 Create new notes
- ✏️ Edit existing notes
- 🗑️ Delete selected notes
- ⭐ Mark notes as favourites
- ✅ Mark notes as completed
- 🔍 Search notes
- 🎨 Custom color for individual notes
- 👀 View notes in a detailed modal
- ☑️ Select multiple notes
- 💾 Persistent data using LocalStorage
- 📱 Clean and simple card-based UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
- Font Awesome
